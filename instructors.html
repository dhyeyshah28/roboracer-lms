      For Roboracer admins
Add a new instructor and their course

      
Team members only. Do this once for each new instructor.

      

        
 1 · Create the user
    
          
  • Sign in to the Courses portal and open the admin console
  • Go to Authentication and Authorization › Users › Add user
  • Enter the user information and save
  • Set the email, mark the account active
  • Tick Staff – only for Roboracer team members. Studio login now works

        
 2 · Add them to a course
    
          
  • Open Studio, then the desired course
  • Settings menu → Course Team → “Add a new team member”
  • Enter their email and make them staff
  • Back as admin, re-run the 4-, 10- or 15-week course
  • Rename it, add the affiliation and add the user as Staff
